# 🌿 EcoGuard AI – Smart Environment Monitoring System

## About the Project
EcoGuard AI is a Python-based environmental monitoring application designed to demonstrate pollution analysis, water quality classification, and environmental risk prediction.

## Features
- 🌍 Environmental Monitoring Dashboard
- 🤖 Air Pollution Risk Predictor
- 🧠 K-Nearest Neighbors (KNN) Classification
- 💧 Water Quality Prediction
- 📊 Weekly Environmental Analytics
- 📄 Automatic PDF Report Generation
- 🔐 Admin Login and Control Panel

## Technologies Used
- Python
- Tkinter
- Machine Learning (KNN)
- Matplotlib (planned for future graph upgrades)
- Python File Handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project in Python IDLE.
4. Run `start.py`.
5. Login using the demonstration credentials configured in `login.py`.

## Important Note
The machine learning modules currently use illustrative sample datasets. Predictions are educational demonstrations, not validated environmental measurements or certified water safety assessments. The login is also a basic demonstration, not production-grade security.
